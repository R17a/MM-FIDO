## Долгосрочные планы

- Поддержка второй прошивки — MeshCore (несовместима с Meshtastic на радиоуровне) и мост между двумя сетями
- Публичная карта хабов сети (с огрублением геопозиции)
- Передача вложений (SVG) по LoRa

## Long-term plans

- Support for a second firmware — MeshCore (incompatible with Meshtastic at the radio level) and a bridge between the two networks
- A public map of the network's hubs (with coarsened geolocation)
- Attachment (SVG) transfer over LoRa

## 长期计划

- 支持第二种固件 —— MeshCore（在无线电层面与 Meshtastic 不兼容），以及两个网络之间的桥
- 网络 HUB 的公开地图（地理位置经过粗化）
- 通过 LoRa 传输附件（SVG）
