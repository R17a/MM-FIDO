# Meshtastic ───●──●──● 🐕 FIDO
<hr>
<p>
Децентрализованная оффлайн-сеть эхоконференций (в духе Fidonet и редактора GoldED) поверх физического радиопротокола Meshtastic (LoRa), с архитектурой фонового тоссинга (синхронизации) в локальную базу данных и криптографической системой модерации.
  <br>
  <a href="https://github.com/R17a/Meshtastic_FIDO/blob/main/Technology.RU.md">Технология</a>
  <br><a href="https://github.com/R17a/Meshtastic_FIDO/blob/main/Demo/RU.md">Демо</a>
  <br>Чат в Телеграм: https://t.me/c/4450883257/4
</p><p>
A decentralized offline echo-conference network (in the spirit of Fidonet and the GoldED editor) running over the physical Meshtastic (LoRa) radio protocol, featuring a background tossing (synchronization) architecture that writes to a local database and a cryptographic moderation system.
  <br>
  <a href="https://github.com/R17a/Meshtastic_FIDO/blob/main/Technology.EN.md">Technology</a>
  <br><a href="https://github.com/R17a/Meshtastic_FIDO/blob/main/Demo/EN.md">Demo</a>
  <br>Telegram chat: https://t.me/c/4450883257/6

</p><p>
这是一个基于 Meshtastic (LoRa) 物理无线电协议运行的去中心化离线“回声会议”（echo-conference）网络，其设计理念承袭自 Fidonet 和 GoldED 编辑器；该网络采用后台数据交换（同步）架构，将数据写入本地数据库，并配备了基于加密技术的审核系统。
